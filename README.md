# Brush & Soul Studio — Shopify theme

Online Store 2.0 theme for brushandsoulstudio.com, ported from the design prototype.
Jewel-toned, arch-framed, with Caroline's artwork as the default imagery.

## Connect to a store
1. Online Store → Themes → Add theme → **Connect from GitHub** → select this repo (`main`).
2. Customize → set the **Featured collection**, logo, and menu in the theme editor.
3. Create pages **About** (template: `about`) and **Commissions** (template: `commissions`).

Sections (editable in the theme editor): hero, vision, category funnel, featured work,
newsletter, about, commissions. Products, prices, and collections are managed in Shopify admin.
Collection pages use Shopify's native filtering (enable via the Search & Discovery app).
